# 06 — Robustness analysis

This folder maps to the paper's openness, leave-one-view, and temporal-shift
experiments.

```bash
bash run.sh temporal
bash run.sh openness
```

The leave-one-view study is launched with
`src/run_final_ast_leave_one_view_ablation.sh` after checkpoints are available.
Reference run-level and summary CSV files are under `results/06_robustness/`.
